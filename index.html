O Submundo dos Bytes

Em uma noite sem lua, o Data Center abandonado da Torre Carmesim foi tomado por Bugs demoníacos. Eles devoraram a memória do sistema e agora guardam 16 portões selados com os termos antigos da Arquitetura Computacional.

Você é o Caçador, último técnico capaz de enfrentá-los. Leia cada pista, decifre o termo e escreva-o no tabuleiro para quebrar o selo de cada portão.

Dica: se travar, use Dica para revelar uma letra ou Resposta para revelar a palavra.

Leia as pistas e selaremos os portões!
